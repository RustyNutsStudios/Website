# Localised EGGREGIOUS pages and media kits

One template, seven languages: English, Russian, Simplified Chinese, Japanese, German, Spanish, Brazilian Portuguese. `eggregious.html` (English) and the six `eggregious-xx.html` pages are all generated by `build_pages.py`.

## What is what

| path | what |
|---|---|
| `store/` | the approved Steam text, short description and About, per language. Copied byte for byte from `EggregiousSteamUpload\22 LOCALISED PAGE\steam_ready`. Never edited here. |
| `strings.json` | the page interface strings (buttons, headings, fact sheet labels). English plus the translator's six languages. |
| `import_strings.py` | reads the translator's `WEBSITE_STRINGS_<lang>.txt` files into `strings.json` |
| `templates/follow-en.html` | the English page's Follow row, kept word for word |
| `build_pages.py` | writes the seven EGGREGIOUS pages, rebuilds `press.html`, updates `sitemap.xml` |
| `build_kits.py` | builds the web images, the fact sheets and the zips in `media-kit/` from Tommy's art folders |
| `../playtest.json`, `../playtest_switch.py` | the playtest switch (below) |
| `../check_site.py` | link, text and rule checks for the whole site (run it before every push) |

## When the translator sends or changes strings

1. `python tools/i18n/import_strings.py` (reads the six files from `22 LOCALISED PAGE\website_strings`)
2. `python tools/i18n/build_kits.py` (fact sheets and zips carry the labels)
3. `python tools/playtest_switch.py` (rebuilds the pages)
4. `python tools/check_site.py` must print `0 failures`

A language with no value for a key shows the English string. Chinese `discord_join` is empty on purpose.

## When the Steam text changes

Replace the file in `store/`, then run steps 2 to 4. The check fails if a page stops showing the approved text word for word.

## The playtest switch

`tools/playtest.json` has one setting, `"open"`. While it is `false` the site is true: no Discord link, no Request Access line, no playtest wording, and the only call to action is Wishlist on Steam, on all seven pages and on the FAQ, devlog, press and home pages. To open the playtest set it to `true`, run `python tools/playtest_switch.py`, then `python tools/check_site.py`, and commit the result as one small commit.

Open brings back the "Join the Discord" button (invite in `i18n_lib.py`), the footer Discord link, on the English page the three playtest steps with the Steam Request Access line, and the playtest FAQ answers. **The Chinese page never shows Discord, open or closed** (Discord is blocked in mainland China): it is Steam only.

## Rules baked into the check

Own game art only. No boss count. No other games' names on the translated pages. No egg puns. No e-mail address. No "keys" and no playtest dates. Developer and publisher (Tommy Allen, Rusty Nuts Studios LLC) appear on every language page and in every fact sheet, as the Steam page shows them. The English footer city stays until Tommy rules.
